## About The Project

Aura is a sleek and modern mobile application for sharing and discovering video content. Built from the ground up with React Native and Expo, it offers a seamless, cross-platform user experience. The app features user authentication, a dynamic content feed, profile management, and more, all wrapped in a beautifully designed interface styled with NativeWind.

## Built With

This project is built with modern mobile development technologies to ensure a high-quality and maintainable codebase.

* [React Native](https://reactnative.dev/)

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need to have Node.js and npm installed on your machine. It is also highly recommended to install the Expo Go app on your physical device for testing.

* **npm**
  ```sh
  npm install npm@latest -g
  ```
* **Expo Go App**
  * [Download for Android](https://play.google.com/store/apps/details?id=host.exp.exponent)
  * [Download for iOS](https://apps.apple.com/us/app/expo-go/id982107779)

### Installation

1. **Clone the repo**
   ```sh
   git clone https://github.com/itsskofficial/Aura.git
   ```

2. **Navigate to the project directory**
   ```sh
   cd Projects/Aura
   ```

3. **Install NPM packages**
   ```sh
   npm install
   ```

4. **Start the development server**
   ```sh
   npx expo start
   ```
   
5. **Run the app**
   * Scan the QR code from the terminal with the Expo Go app on your phone.
   * Or, press `i` to run on an iOS simulator or `a` to run on an Android emulator.

## Usage

Aura provides an intuitive platform for video content. Users can:
* Sign up and log in to their accounts securely.
* Browse a feed of trending and recommended videos.
* Create and upload their own video content.
* Bookmark their favorite videos for later viewing.
* Manage their user profile and settings.
